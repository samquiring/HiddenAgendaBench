# Historical development experiments

These scripts preserve the pilot, prompt/format study, reasoning-control probes,
and their report generators. They are not the default evaluation protocol.
Run them from the repository root with the package installed.

The default workflow is `hidden-agenda prepare`, `run`, `report`, and `analyze`.
Earlier output directories under `runs/` remain untouched and are ignored by Git.

Historical scripts retain their original model assumptions and exclusive output
creation. Their source hashes differ after this organizational move; existing
manifests and saved runs have not been rewritten.
